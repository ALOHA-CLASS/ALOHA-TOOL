# 이미지 해상도 향상

`input` 폴더의 이미지를 지정한 배율로 확대하여 `output` 폴더에 저장합니다.
실행 시 처리 방식을 선택할 수 있습니다.

1. **단순 해상도 확장**: Lanczos 리샘플링으로 크기를 늘립니다.
2. **AI 디테일 복원**: 사전 학습된 FSRCNN x4 초해상도 모델로 이미지를 처리합니다.
   AI가 추정한 디테일이므로 원본에 없던 실제 정보를 완벽히 복구하지는 못합니다.

## 설치 및 실행

Python 3.10 이상이 필요합니다. 이 폴더에서 다음 명령을 실행합니다.

```powershell
pip install -r requirements.txt
python main.py
```

이미지를 `input` 폴더에 넣고 실행한 뒤 처리 방식과 확대 배율을 입력하세요. 예를 들어
`2`는 가로와 세로를 각각 2배, `1.5`는 각각 1.5배로 확대합니다.
비율은 유지하고 소수점 픽셀은 반올림합니다. 배율은 1 이상의 숫자여야 합니다.

명령줄 옵션도 사용할 수 있습니다:

```powershell
python main.py --mode simple --scale 2
python main.py --mode ai --scale 2
python main.py --scale 1.5 --input "C:\images" --output "C:\enlarged"
```

`--scale`만 지정하면 기존과 같이 단순 확장을 사용합니다. AI 모드는 최초 실행 시
[FSRCNN x4 모델](https://github.com/Saafke/FSRCNN_Tensorflow)을 다운로드하여
사용자 홈의 `.cache\aloha-image-upscale`에 저장하고 SHA-256으로 검증합니다.
이미지 파일은 외부로 전송하지 않고 CPU에서 처리합니다. 인터넷 연결이 없으면
모델을 미리 다운로드하여 `--mode ai --model "모델파일경로" --scale 2`로 지정할 수
있습니다. 지정한 모델도 같은 SHA-256 검증을 통과해야 합니다.

## 처리 방식 및 제한

- AI는 내부적으로 4배 복원한 후 요청한 크기로 Lanczos 리샘플링합니다. 4배를 초과하는 배율은 나머지 부분을 일반 확대하므로 AI가 더 많은 디테일을 만들어내지는 않습니다. 1배도 복원 후 원래 크기로 축소됩니다.
- AI는 CPU를 사용하므로 단순 확장보다 느리며, 내부 4배 이미지도 최대 8,000만 픽셀로 제한됩니다. 색상은 8비트 RGB로 처리하고 알파 채널은 별도로 확대하므로 고비트 심도는 유지되지 않습니다. 비 RGB 이미지의 색상 프로필은 변환 후 적용할 수 없어 제거됩니다.
- 입력 폴더 바로 아래의 JPG, JPEG, PNG, WebP, BMP, TIFF, GIF, AVIF 파일을 처리합니다. 대소문자는 구분하지 않으며 하위 폴더는 처리하지 않습니다. AVIF 등 일부 형식은 설치된 Pillow 빌드의 지원이 필요합니다.
- 원본 형식으로 저장하고 투명도와 이미지 방향을 반영합니다. JPEG는 품질 95, WebP는 무손실로 저장합니다. JPEG 원본의 압축 손상은 완전히 복구되지 않습니다.
- GIF 등 일부 형식은 색상과 투명도 표현에 제한이 있습니다.
- 원본은 변경하지 않습니다. 같은 이름의 결과가 있으면 `_1`, `_2` 등을 붙여 기존 파일을 보존합니다. 입력과 출력 폴더는 서로 달라야 합니다.
- 애니메이션 및 다중 페이지 이미지는 프레임 손실을 방지하기 위해 처리하지 않고 실패로 표시합니다. 손상된 이미지도 실패로 표시하며 나머지 이미지는 계속 처리합니다.
- 메모리 보호를 위해 출력 크기는 이미지당 최대 8,000만 픽셀입니다. 실제 사용 가능한 메모리에 따라 더 작은 이미지도 실패할 수 있습니다.
- 처리할 이미지가 없거나 하나라도 실패하면 종료 코드는 1입니다. 모두 성공하면 0입니다.

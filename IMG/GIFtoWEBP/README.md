# GIF → 애니메이션 WEBP 변환 프로그램

input 폴더의 GIF 파일들을 애니메이션 WEBP로 변환하여 output 폴더에 저장하는 프로그램입니다.

## 주요 특징

- **애니메이션 유지**: GIF의 모든 프레임과 재생 속도(duration), 반복 횟수(loop)를 그대로 보존
- **높은 압축률**: WEBP는 동일한 품질에서 GIF보다 용량이 훨씬 작음
- **품질 조절 가능**: 손실 압축(quality) 또는 무손실(lossless) 선택 가능

## 사전 준비

### 라이브러리 설치

```powershell
pip install -r requirements.txt
```

## 사용 방법

1. `input` 폴더에 변환할 GIF 파일을 넣습니다
2. 프로그램을 실행합니다:

```powershell
python main.py
```

3. 변환된 WEBP 파일이 `output` 폴더에 생성됩니다 (동일한 파일명, 확장자만 `.webp`)

## 변환 설정 조정

`main.py`의 다음 값들을 조정할 수 있습니다:

- **QUALITY** (현재: 80)
  - 0-100 범위, 낮을수록 용량 작고 품질 낮음 (권장: 75-90)
  - `LOSSLESS = True`일 때는 적용되지 않음
- **LOSSLESS** (현재: False)
  - `True`로 설정하면 무손실 변환 (품질 저하 없음, 대신 용량이 커질 수 있음)
- **METHOD** (현재: 6)
  - 0(빠른 압축)-6(느리지만 압축률 높음)

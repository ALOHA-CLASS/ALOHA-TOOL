# GIF / 애니메이션 WEBP 압축 + 리사이징 프로그램

input 폴더의 애니메이션 GIF·WEBP 파일을 압축하고, 가로세로 비율을 유지한 채 리사이즈하여 output 폴더에 저장하는 프로그램입니다.

## 주요 특징

- **GIF와 WEBP 모두 지원**: 입력 파일의 확장자를 그대로 유지한 채 압축 (GIF → GIF, WEBP → WEBP)
- **비율 유지 리사이징**: 가로 크기만 입력하면 세로는 원본 비율에 맞춰 자동 계산
- **애니메이션 보존**: 모든 프레임, 재생 속도(duration), 반복 횟수(loop) 유지
- **실행 시 설정 입력**: 프로그램 시작 시 목표 가로 크기와 압축 품질을 직접 입력

## 사전 준비

### 라이브러리 설치

```powershell
pip install -r requirements.txt
```

## 사용 방법

1. `input` 폴더에 압축/리사이즈할 GIF 또는 WEBP 파일을 넣습니다
2. 프로그램을 실행합니다:

```powershell
python main.py
```

3. 실행하면 아래 두 가지를 입력합니다:
   - **목표 가로 크기(px)**: 비워두고 Enter를 누르면 원본 크기 유지, 숫자를 입력하면 해당 가로 크기로 리사이즈 (세로는 비율에 맞춰 자동 계산)
   - **압축 품질(1-100)**: 낮을수록 용량이 작아짐 (기본값 80)
4. 압축/리사이즈된 파일이 `output` 폴더에 원본과 같은 파일명·확장자로 생성됩니다

## 압축 방식

- **WEBP**: 품질(quality) 수치를 그대로 적용하는 손실 압축 (method 5)
- **GIF**: JPEG/WEBP처럼 품질 수치가 없기 때문에, 입력한 품질을 팔레트 색상 수(2-256)로 환산해 압축률을 조절합니다. 애니메이션 전체에서 색상이 흔들리지 않도록 프레임을 샘플링해 공용 팔레트를 만든 뒤 적용합니다.

## 참고 사항

- 투명도(알파 채널)가 있는 GIF는 팔레트 변환 과정에서 투명 영역이 완벽하게 보존되지 않을 수 있습니다. (사진/배경이 불투명한 애니메이션에 최적화)
- 프레임 수가 많은 애니메이션(수백 프레임)은 압축에 다소 시간이 걸릴 수 있습니다.
